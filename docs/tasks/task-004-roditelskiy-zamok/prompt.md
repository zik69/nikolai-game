# Задание для ИИ: родительский замок

Добавь в страничку потайную дверь для взрослого.

Требования:

- Маленькая кнопка в углу, без подписи, не яркая.
- Открывается удержанием пальца три секунды (показывай кольцо-заполнение).
- Внутри: звук вкл/выкл, ограничение времени игры, кнопка «выйти».
- Выход спрашивает подтверждение.
- Если взрослый ушёл, панель закрывается сама через полминуты.
- Настройки хранятся в браузере и восстанавливаются после перезагрузки.
- Ребёнок, тыкающий по экрану, не должен открыть панель случайно.

Проверь: десять случайных касаний подряд панель не открывают.
