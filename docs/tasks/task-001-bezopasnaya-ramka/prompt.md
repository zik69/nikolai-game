# Задание для ИИ: безопасная рамка

Сделай одну страничку `index.html` для годовалого ребёнка — пока только рамку,
без игр.

Требования:

- Страница на весь экран, без прокрутки и без «резинки».
- Запрещено увеличение двойным касанием и щипком.
- Долгое нажатие не выделяет картинку и не открывает меню браузера.
- Пока страница открыта, экран не гаснет (если браузер разрешает).
- Внутри — только крупный спокойный фон и одна большая кнопка-заглушка
  «начать», без текста, который надо читать.
- Никаких внешних ссылок, шрифтов и картинок из интернета: всё внутри файла.
- Всё работает, если файл открыть двойным щелчком, без сервера.

Проверь на телефоне и на планшете: ничего не листается, не растягивается,
не выделяется. Напиши в ответе, что не удалось сделать средствами браузера.
