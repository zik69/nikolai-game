# Задание для ИИ: пальчиковые дорожки

Добавь в игру для годовалого ребёнка четвёртую игру — рисование пальцем.

Требования:

- В панели взрослого четыре игры: «Звери», «Пузыри», «Небо», «Рисование».
- Прозрачный слой на весь экран, рисунок ложится поверх неба и луга.
- Ведёшь пальцем — остаётся толстая линия со скруглёнными концами,
  толщина примерно 4% от меньшей стороны экрана.
- Каждый новый штрих — новый цвет из яркой палитры (красный, оранжевый,
  зелёный, голубой, фиолетовый, розовый).
- Поддержка нескольких пальцев одновременно.
- Стирание — только кнопкой «Стереть рисунок» в панели взрослого.
- Учитывай плотность пикселей (devicePixelRatio), чтобы линия не была мыльной
  на iPad.
- Не ломать остальное: замок, таймер, ночной экран, запрет сети.

Проверь на iPad 1024×768 и 768×1024: линия идёт точно под пальцем.
