# Задание для ИИ: музыкальные звери

Добавь пятую игру для годовалого ребёнка — «Музыкальные звери».

Требования:

- Пять зверей: кошка, мишка, уточка, зайка, лягушка. Нарисованы кодом.
- У каждого своя нота из пентатоники: до, ре, ми, соль, ля первой октавы
  (261.63, 293.66, 329.63, 392.00, 440.00 Гц).
- Звук мягкий: синус плюс тихая октава сверху, плавное начало, затухание
  около 0.9 секунды. Без резких атак.
- Нажатие — сразу нота, зверь подпрыгивает и вокруг вспыхивает цветной круг.
- Несколько пальцев — несколько нот одновременно.
- Выключенный звук в замке глушит ноты, прыжок остаётся.
- Раскладка: лёжа пять зверей в ряд, стоя — столбиком, крупно.
- Не ломать остальное: замок, таймер, ночной экран, запрет сети.

Проверь на iPad 1024×768 и 768×1024.
