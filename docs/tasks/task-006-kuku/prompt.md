# Задание для ИИ: игра «ку-ку»

Добавь в игру для годовалого ребёнка игру «ку-ку».

Требования:

- Нажал на персонажа — его закрывают две большие мягкие ладошки
  (движение около 0,3 секунды).
- Ладошки держатся меньше секунды и расходятся, персонаж «выпрыгивает»
  обратно с лёгким увеличением.
- В момент появления звучит «ку-ку»: две короткие нотки, вторая ниже первой,
  мягко и негромко. Звук создаётся кодом, без файлов.
- Звук самого персонажа играет сразу при нажатии, как раньше.
- Пока идёт «ку-ку», повторное нажатие по этому же персонажу игнорируется.
- Ладошки закрывают персонажа целиком и на широком экране, и на узком.
- Ничего не ломать: замок, таймер, выключение звука, отсутствие интернета.

Проверь на размерах iPad 1024×768 и 768×1024.
