# Задание для ИИ: голоса родителей

Добавь в игру для годовалого ребёнка запись своих голосов.

Требования:

- В панели взрослого блок «Свой голос»: три кнопки (кошка, мишка, машинка)
  и кнопка «Стереть все». Под ними — короткая подсказка словами.
- Нажатие на кнопку зверя: getUserMedia({audio:true}), запись 3 секунды
  через MediaRecorder, автоматическая остановка. Повторное нажатие во время
  записи останавливает раньше.
- Готовую запись превратить в base64 и сохранить в localStorage, чтобы она
  пережила перезагрузку. Размер одной записи — несколько килобайт.
- Для проигрывания декодировать запись через AudioContext.decodeAudioData
  и играть через AudioBufferSourceNode (никаких новых сетевых запросов
  и никаких изменений в CSP).
- В игре «Звери»: если для зверя есть запись — играть её вместо
  синтезированного звука; иначе как раньше.
- Ошибки: нет микрофона, нет разрешения, браузер не поддерживает запись —
  показать понятный текст в панели, игру не ломать.
- Всё работает без интернета; звук, таймер и замок не ломать.

Проверь в Chrome на localhost и на iPad по https.
