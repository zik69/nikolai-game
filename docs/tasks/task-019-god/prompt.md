# Задание для ИИ: времена года

Добавь в игру для годовалого ребёнка десятую игру — «Год».

Требования:

- В панели взрослого кнопка «Год». При выборе этой игры в панели появляется
  строка «Время года» с четырьмя кнопками: зима, весна, лето, осень.
  В других играх строку не показывать.
- Сценка: небо-градиент, поляна, дерево по центру и падающие частицы (26 штук).
- Цвета: зима — белая поляна, снежная крона, белый снег; весна — светло-зелёная
  поляна, розовые цветы и лепестки; лето — зелёная поляна, зелёная крона,
  светлые искорки; осень — рыжая поляна, оранжевая крона, падающие листья.
- Частицы падают 9–17 секунд, слегка сносятся в сторону, вращаются.
- Касание экрана: расходящийся кружок цвета времени года и тихий звон.
- Выбор времени года запоминать в localStorage.
- Всё без интернета, без новых файлов.

Проверь на iPad 1024×768 и 768×1024.
