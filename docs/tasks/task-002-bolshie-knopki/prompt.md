# Задание для ИИ: большие картинки-кнопки

Возьми готовую рамку из задачи 001 и положи на неё двух-трёх персонажей.

Требования:

- Персонажи нарисованы прямо в файле (простые фигуры), без картинок из сети.
- Каждый занимает не меньше трети ширины экрана, отступы между ними большие.
- Нажатие ловится по всей площади персонажа.
- Вёрстка не ломается, когда телефон поворачивают боком.
- Главное устройство — iPad: проверь на 1024×768 и на 768×1024, чтобы всё
  было крупно и по краю картинки нажатие срабатывало.
- Пока без звука и без движения: только крупные фигуры и лёгкое изменение
  вида при нажатии, чтобы было видно, что нажатие сработало.
- Никакого текста на экране.

Проверь, что по краю картинки нажатие срабатывает именно на ней.
