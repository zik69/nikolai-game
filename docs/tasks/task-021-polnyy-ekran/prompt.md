# Задание для ИИ: кнопка «Во весь экран»

Добавь в игру для годовалого ребёнка кнопку полного экрана в панели взрослого.

Требования:

- В панели взрослого кнопка «Во весь экран». В полном экране подпись меняется
  на «Выйти из полного экрана».
- Нажатие вызывает requestFullscreen на documentElement с navigationUI: hide.
  Повторное нажатие — exitFullscreen.
- Если метод недоступен или Promise отклонён, показать карточку-подсказку
  (не alert и не ошибку в консоли):
  1) «На экран „Домой“»: Safari → «Поделиться» → «На экран „Домой“»;
  2) «Направленный доступ»: Настройки → Универсальный доступ →
     Направленный доступ, тройное нажатие боковой кнопки.
- Подсказка на русском, простыми словами, закрывается кнопкой «Понятно».
- Пока подсказка открыта, игра на паузе.
- Обновлять подпись кнопки по событию fullscreenchange (и webkit-версии).
- Убрать автоматический вход в полный экран по первому касанию ребёнка:
  теперь это решение взрослого.

Проверь на iPad 1024×768 и 768×1024, а также в браузере без поддержки
полного экрана.
