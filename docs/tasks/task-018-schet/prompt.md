# Задание для ИИ: счёт до трёх

Добавь в игру для годовалого ребёнка девятую игру — «Счёт».

Требования:

- В панели взрослого кнопка «Счёт».
- По центру три места для мячиков; сначала все скрыты.
- Касание в любом месте экрана показывает следующий мячик (1 → 2 → 3)
  с пружинистым появлением за 0,35 секунды.
- У мячиков разные цвета: красный, синий, зелёный; размер около 22vmin.
- На каждом мячике играет своя нота: до, ми, соль (523.25, 659.25, 783.99 Гц).
- Если доступен speechSynthesis, произнести «один», «два», «три» по-русски
  (lang ru-RU, rate 0.85, volume 0.9). Если нет — просто ноты.
- После третьего мячика: через 0,9 секунды мячики подпрыгивают и звучит
  колокольчик, через 2,4 секунды всё сбрасывается и игра начинается заново.
- Во время сброса новые касания игнорируются.
- Выключенный звук глушит и ноты, и голос.
- Не ломать остальное: замок, таймер, ночной экран, запрет сети.

Проверь на iPad 1024×768 и 768×1024.
