# Задание для ИИ: тихая страничка перед сном

Добавь в игру для годовалого ребёнка восьмую игру — тихую ночную.

Требования:

- В панели взрослого кнопка «Сон».
- Ночное небо: тёмно-синий градиент, около 40 мелких звёзд с медленным
  мерцанием (4–9 секунд), большая луна с мягким свечением.
- Тёмные силуэты холмов, на переднем плане спящий мишка (закрытые глазки),
  он медленно «дышит» — масштаб меняется на 3% за 6 секунд.
- Над мишкой медленно плывут «z z z».
- Колыбельная: медленная мелодия из 12 нот, каждая 1,1–2,4 секунды, играет
  по кругу. Синус, очень тихо, плавное начало и долгое затухание, плюс тихая
  октава снизу. Звук создаётся кодом.
- Касание экрана — звёздочка в этом месте, гаснет за 1,6 секунды. Без звука.
- Уход из игры останавливает музыку; возврат запускает снова.
- Выключенный звук глушит колыбельную.
- Не ломать остальное: замок, таймер, ночной экран, запрет сети.

Ничего не должно мигать чаще, чем раз в секунду. Проверь на iPad 1024×768
и 768×1024.
