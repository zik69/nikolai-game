# Задание для ИИ: ладушки

Добавь в игру для годовалого ребёнка шестую игру — «Ладушки».

Требования:

- В панели взрослого шестая кнопка «Ладушки».
- В центре экрана две большие ладошки друг напротив друга, нарисованы кодом.
- Экран сам отбивает ритм: хлопки на 0, 480 и 1600 мс, цикл 2500 мс.
  На каждом хлопке ладошки сходятся за 0,3 секунды и расходятся.
- Звук хлопка — короткий шумовой всплеск с полосовым фильтром, мягкий,
  не резкий. Создаётся кодом, без файлов.
- Касание в любом месте экрана — дополнительный хлопок (звук и движение),
  ритм при этом не сбивается.
- Никаких оценок и штрафов.
- Уход из игры останавливает ритм; возврат — запускает снова.
- Выключенный звук глушит хлопки, движение остаётся.
- Не ломать остальное: замок, таймер, ночной экран, запрет сети.

Проверь на iPad 1024×768 и 768×1024.
