# Задание для ИИ: падающие звёзды в ночном режиме

Добавь в ночную игру для годовалого ребёнка медленные падающие звёзды,
которые можно ловить.

Требования:

- Четыре звезды одновременно, появляются сразу при включении ночного режима,
  расставлены равномерно по небу.
- Звезда летит сверху вниз 28–42 секунды и слегка покачивается влево-вправо.
- Размер 3–6vmin, форма — четырёхлучевая звезда с мягким свечением.
- Касание: звезда останавливается, увеличивается в 1,9 раза и тает за
  0,7 секунды; звучит тихий высокий звон (синус, долгое затухание).
- Через 1,4 секунды звезда возвращается сверху уже в другом месте.
- Одновременно больше четырёх звёзд не бывает.
- Звёзды падают за холмами и медведём, не перекрывают луну.
- Выключенный звук глушит звон.
- Ничего не ускорять, не добавлять очков и «поймал/не поймал».

Проверь на iPad 1024×768 и 768×1024.
