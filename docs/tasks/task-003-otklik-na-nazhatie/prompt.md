# Задание для ИИ: отклик на нажатие

Добавь к персонажам из задачи 002 движение и звук.

Требования:

- Звук создаётся кодом (короткие ноты или «пики»), без звуковых файлов
  и без ссылок в интернет.
- Звук короткий, не громче обычного, без резкого начала.
- Картинка двигается сразу после нажатия и возвращается на место.
- Быстрые повторные нажатия не ломают анимацию и не глушат звук.
- На телефоне звук включается после первого касания (браузеры не дают
  играть звук до первого действия человека) — учти это и не показывай ошибок.
- Проверь, что всё работает при выключенном интернете.

В ответе напиши, какие звуки получились и где может быть тихо на iPhone.
