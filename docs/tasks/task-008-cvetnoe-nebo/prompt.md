# Задание для ИИ: цветное небо

Добавь третью игру для годовалого ребёнка — «Цветное небо».

Требования:

- В панели взрослого три игры: «Звери», «Пузыри», «Небо». Выбор запоминается.
- В режиме «Небо» на экране только небо, солнце, облака и луг.
- Касание в любом месте переключает палитру на следующую: утро, закат,
  розовый, сиреневый, мятный — и снова утро.
- Небо меняется плавно, примерно за 1,3 секунды, без резких вспышек.
  Градиент меняется через плавное проявление второго слоя.
- Солнце меняет цвет мягко, переходом 1,2 секунды.
- Звук — тихий колокольчик из двух нот; выключенный звук его глушит.
- Всё работает без интернета и без внешних файлов.
- Таймер, ночной экран и защита от случайных жестов продолжают работать.

Проверь на iPad 1024×768 и 768×1024: цвет заливает весь экран, без белых краёв.
