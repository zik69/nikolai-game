# Задание для ИИ: большой и маленький

Добавь в игру для годовалого ребёнка седьмую игру — «Размер».

Требования:

- Две колонки: слева большой домик и большой мишка, справа маленький домик
  и маленький мишка.
- Домики нарисованы кодом: крыша, стены, дверь-арка. Дверь — невидимая зона
  для проверки попадания.
- Мишек можно тянуть пальцем через весь экран (pointer events + transform),
  мишка приподнимается и отбрасывает тень.
- Проверка попадания: центр мишки внутри двери своего размера.
- Попал — мишка уезжает в дверь, уменьшается, исчезает, звучит колокольчик.
- Не попал — мишка пружинкой возвращается на место, без звука ошибки.
- Когда оба мишки дома — домики подпрыгивают, звучит колокольчик, через
  1,6 секунды игра начинается заново.
- Никаких очков и «неправильно».
- Не ломать остальное: замок, таймер, ночной экран, запрет сети.

Проверь на iPad 1024×768 и 768×1024.
