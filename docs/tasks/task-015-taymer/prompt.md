# Задание для ИИ: мягкий таймер игры

Сделай плавное завершение сеанса в игре для годовалого ребёнка.

Требования:

- Экран «Пора отдохнуть» появляется с растворением: сначала темнота за
  2,2 секунды, затем через полсекунды проявляются луна и текст (ещё 1,2 с).
- Никакого резкого переключения: элемент не должен мигать.
- В момент засыпания играют две тихие нисходящие ноты (синус, долгое
  затухание), все игровые звуки (хлопки, колыбельная) останавливаются.
- Возврат в игру: ночной экран растворяется за 2,2 секунды, таймер считается
  заново.
- Пока идёт засыпание, нажатия не работают.
- Не ломать остальное: замок, игры, запрет сети, кнопку выхода.

Проверь на iPad 1024×768 и 768×1024.
