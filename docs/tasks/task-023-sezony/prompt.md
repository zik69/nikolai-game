# Задание для ИИ: сезонные забавы

Добавь в игру «Год» по одному маленькому делу на каждое время года.

Требования:

- Зима: снеговик из трёх снежных комов. Каждое касание добавляет следующий
  ком (снизу вверх) с пружинистым появлением. После третьего появляются
  морковка и глазки, снеговик покачивается, через 2,6 секунды исчезает —
  можно лепить заново. Звук — мягкий снежный «пух».
- Весна: касание в точке касания распускает цветок (лепестки раскрываются
  за 0,4 секунды). До шести цветов, каждый звенит своей нотой из пентатоники.
  После шестого через 1,8 секунды цветы тихо исчезают.
- Лето: три бабочки медленно перелетают по поляне (12–18 секунд на круг).
  Касание бабочки — она вспархивает вверх и тает, через 2,5 секунды прилетает
  новая. Звук — тихий звон.
- Осень: касание запускает лист, который летит с неба в кучу внизу за
  0,7 секунды. Куча растёт с каждым листом, после пятого подпрыгивает
  и очищается.
- При смене времени года очищать всё лишнее.
- Никаких очков и подсказок «правильно».

Проверь на iPad 1024×768 и 768×1024.
