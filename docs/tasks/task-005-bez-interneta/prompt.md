# Задание для ИИ: страничка без интернета

Собери всё, что уже сделано, в один файл `index.html`, который работает
без связи.

Требования:

- Ни одной внешней ссылки: ни шрифтов, ни картинок, ни скриптов, ни счётчиков.
- Все картинки нарисованы кодом, звуки создаются кодом.
- Файл открывается двойным щелчком с рабочего стола, без сервера.
- Проверь в «режиме самолёта»: ничего не пропало.
- В конце перечисли, что лежит внутри файла и сколько он весит.

Ничего не отправляй в интернет и не добавляй рекламу.
