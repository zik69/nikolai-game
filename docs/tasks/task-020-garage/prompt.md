# Задание для ИИ: гараж

Добавь в игру для годовалого ребёнка одиннадцатую игру — «Гараж».

Требования:

- В панели взрослого кнопка «Гараж».
- Гараж по центру внизу: стены, крыша, большая подъёмная дверь.
- Внутри стоит красная машинка, её не видно за закрытой дверью.
- Касание в любом месте: дверь уезжает вверх за 0,35 секунды, звучит сигнал,
  машинка выезжает вправо на 34vw, разворачивается и возвращается.
  Весь заезд — 3,2 секунды.
- Потом дверь закрывается за 0,35 секунды, и через 0,4 секунды машинка
  «прячется» (сбрасывается), чтобы можно было повторить.
- Пока идёт заезд, касания игнорируются.
- Уход из игры сбрасывает заезд.
- Не ломать остальное: замок, таймер, ночной экран, запрет сети.

Проверь на iPad 1024×768 и 768×1024.
